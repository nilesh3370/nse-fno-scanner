# NSE F&O News + Technical Daily Option Seller's Scanner (v2)

Upgraded daily NSE F&O directional scanner combining **live news catalyst sentiment + technical structure** across 60 liquid NSE F&O stocks, with **Dual-Expiry strike sets (Current Month & Next Month)** and the **≤ 45-Day Next-Month Roll Rule**.

## Important GitHub Setup Note
Place the **contents** of this folder (`index.html`, `scanner.py`, `picks.json`, `requirements.txt`, and `.github/`) directly at the **root** of your GitHub repository (not inside a subfolder) so GitHub Actions detects `.github/workflows/daily_scan.yml`.
